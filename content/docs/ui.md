### 基本操作
基本的な操作方法は以下の通りです。

1. 銘柄、開始・終了を入力
2. メニューの処理をクリック
3. 下の出力内容を確認

処理によっては、入力が不要になる項目があります。例えば、最大期間を設定する処理は、開始・終了の入力が不要です。


### 入力内容
入力できる内容は以下の通りです。

- 銘柄: 半角英数, 半角記号
- 開始・終了: 日付「yyyy-MM-dd」, 西暦「yyyy」

銘柄は、CSVを配置する銘柄フォルダの名前と一致している必要があります。


## 期間の補正
入力された開始・終了の期間は、休日などの非営業日もあるため、範囲内で補正をすることがあります。

出力内容の分析期間もご確認頂くようお願い致します。


## 開始エリアの西暦
開始エリアが西暦の場合、前年の年末に変換します。

入力が「2025」だと、2024年から2025年にまたがるデータが必要になります。

```csv {filename="例: CSVの抜粋"}
Date,Close,Dividends
2024-12-27,10438,0
2024-12-30,10421,0
2025-01-06,10502,0
```

年末を判定する際に、年の切り替わりを利用するためです。


## 終了エリアの西暦
終了エリアが西暦の場合、その年の年末に変換されます。

入力が「2025」だと、2025年から2026年にまたがるデータが必要になります。

```csv {filename="例: CSVの抜粋"}
Date,Close,Dividends
2025-12-29,10438,0
2025-12-30,10421,0
2026-01-05,10502,0
```

年末を判定する際に、年の切り替わりを利用するためです。
