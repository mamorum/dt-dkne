## 設定の追加
EXEと同じ場所に `dt-dkne.ini` を追加すると、アプリの設定を行うことができます。

設定は「`項目名=値`」で追加できます。

```
DataDir=D:\invest\csv\daily
InitTicker=mb-spx
InitStart=2020-12-30
InitEnd=2025
```

## 設定項目
### DataDir
データフォルダの絶対パスを指定することができます。

### InitTicker
銘柄エリアの初期値を指定することができます。

### InitStart
開始エリアの初期値を指定することができます。

### InitEnd
終了エリアの初期値を指定することができます。


## コメント・空行
行が `;` で始まる場合、コメントの扱いになります。

コメントと空行は評価されません。


## エンコーディング 
設定ファイルは、「UTF-8」にする必要があります。
