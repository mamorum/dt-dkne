## ZIPの解凍
ダウンロードしたZIPファイルを解凍します。


## アプリのコピー
DtDkne.exe を、ユーザーフォルダ配下などの書き込み可能な場所にコピーします。

| コピー先のパス                 | 例                                   |
| :----------------------------- | :----------------------------------- |
| %USERPROFILE%\Dkne             | C:\Users\ユーザー名\Dkne             |
| %USERPROFILE%\Documents\Dkne   | C:\Users\ユーザー名\Documents\Dkne   |
