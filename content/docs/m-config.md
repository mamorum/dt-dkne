## 最大期間
開始と終了のエリアに、日付の最大期間を設定します。

最大期間は、CSVに存在する範囲になります。


## 年最大期間
開始と終了のエリアに、西暦の最大期間を設定します。

開始と終了の年末を判定するため、最低でも3年にまたがるデータが必要になります。

``` {filename="CSVの解説"}
Date,Close,Dividends
2024-12-27,10246,0
2024-12-30,10220,0 <- 年末
2025-01-06,10192,0
...
2025-12-29,11619,0
2025-12-30,11693,0 <- 年末
2026-01-05,11721,0
```


## MD表出力
表出力をマークダウンに設定します。

``` {filename="例: Markdownの表"}
|条件|収益率|
|---:|---:|
|一括|380.47%|
|毎年|111.34%|
|毎月|102.02%|
```

上のマークダウンは、以下のような表を表しています。

|条件|収益率|
|---:|---:|
|一括|380.47%|
|毎年|111.34%|
|毎月|102.02%|
